  • สายเข้า Call Center ลดลง → วัดจากสัดส่วนคำถามที่จบในแชทโดยไม่ต้องส่งต่อ

  • เจ้าหน้าที่ได้สรุปบทสนทนาและข้อมูลบัญชีทันที ลูกค้าไม่ต้องเล่าเรื่องซ้ำ เวลาคุยต่อสายสั้นลง
  • ลูกค้าเลือกช่องทางได้ทั้งแชท โทรกลับ หรือนัดสาขา
เบื้องหลังระบบ

ข้อมูล กติกา และความปลอดภัย

สิ่งที่ต้องวางไว้ก่อนพัฒนา เพื่อให้ทั้งสองฟีเจอร์ใช้งานได้จริงในธนาคารรัฐ

แหล่งข้อมูล

  • ระบบสินเชื่อ (Core Loan): ยอดหนี้ ตารางผ่อน อัตราดอกเบี้ย
  • ฐานราคาประเมินทรัพย์ของธนาคาร + ดัชนีราคาที่อยู่อาศัย
  • ระบบเอกสาร (e-Document) และบริษัทประกันพาร์ทเนอร์
  • เครือข่ายช่างหรือผู้รับเหมาที่ผ่านการคัดเลือก

กติกาของ AI (Guardrails)

  • ตัวเลขทุกตัวมาจาก API ไม่ให้โมเดลคำนวณหรือเดาเอง
  • ทำธุรกรรมแทนลูกค้าไม่ได้ ทำได้แค่เตรียมคำขอ ลูกค้าต้องยืนยันเอง
  • ไม่ให้คำแนะนำการลงทุน และบอกเสมอว่าค่าประมาณไม่ใช่ผลอนุมัติ
  • ส่งต่อเจ้าหน้าที่เมื่อไม่มั่นใจ หรือเมื่อตรวจพบความเปราะบาง

ข้อมูลส่วนบุคคล (PDPA)

  • ขอความยินยอมแยกสำหรับประเมินมูลค่าบ้าน OCR เอกสาร และแชร์ข้อมูลให้พาร์ทเนอร์
  • เอกสารเข้ารหัส ลิงก์แชร์มีวันหมดอายุและบันทึกการเข้าถึง
  • บทสนทนาเก็บตามระยะเวลาที่กำหนด และลูกค้าลบประวัติได้

ลำดับพัฒนา

  • ขั้น 1: ตู้เอกสาร + แจ้งเตือน + ทางลัด AI (หนังสือรับรอง, สถานะ)
  • ขั้น 2: แชทอธิบายงวด + มาตรการช่วยเหลือ + ส่งต่อเจ้าหน้าที่
  • ขั้น 3: มูลค่าบ้าน/Equity + ต่อประกัน + ช่างและสินเชื่อซ่อมแซม + โหมดเสียง

เอกสารแนวคิดเพื่อการนำเสนอ ไม่ใช่ดีไซน์ทางการของธนาคาร ตัวเลข ชื่อ ที่อยู่ อัตราดอกเบี้ย และเบี้ยประกันทั้งหมดเป็นข้อมูลตัวอย่าง
